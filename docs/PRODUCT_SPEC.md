# CopyPreflight — 产品规格

> 本文件记录产品定位、冻结原则与范围。**状态：v0.1 范围已冻结。**
> 修改本文件等于修改产品范围，必须在明确的里程碑授权下进行。

## 1. 产品定位

CopyPreflight 是一个 **Windows 文件迁移前检查工具**。

核心理念：

> **先体检，再搬家。**

用户在未来会指定：

1. **源目录**（source）
2. **目标目录**（target）

程序对源目录进行**只读扫描**，并判断这些内容迁移到目标位置时，可能遇到的：

- 兼容性风险
- 可行性问题
- 行为差异

CopyPreflight 只做一件事：**告诉用户在搬家前需要知道的事**。

### 它不是复制软件

CopyPreflight 不负责搬运数据，也不代替用户的复制工具。它给出的是迁移前的判断和建议，最终是否迁移、如何迁移由用户决定。

## 2. 只读原则（冻结）

以下原则在 v0.1 中不可协商：

- **不执行复制**
- **不执行移动**
- **不删除文件**
- **不自动重命名**
- **不修改权限**
- **不格式化磁盘**
- **不自动修复**
- **不向源目录或目标目录写入 probe 文件**

程序对源目录与目标目录的访问是**只读**的。任何"为了验证能力而先写一个测试文件"的做法都违反该原则。

## 3. 未知能力必须保持 Unknown

目标文件系统的能力（例如某个目标是否支持稀疏文件、是否区分大小写、ACL 语义等）在无法被**确定地**观测时，必须标记为 **Unknown**。

**不允许猜测。** 不允许把"通常如此"当作事实写入结论。Unknown 是合法的、必须显式表达的状态。

## 4. 目录映射语义

迁移映射按相对路径对齐：

```text
source\<relative-path>  →  target\<relative-path>
```

**目标目录本身就是迁移内容的目标根目录。**

也就是说，源目录的根会映射到目标目录的根，源目录内部的相对结构在目标目录下被重建。这一语义是路径兼容性、路径长度、冲突检测等一系列规则的共同前提。

## 5. Severity 定义

Severity 不是普通的"严重 / 中等 / 轻微"，它表达的是**判断的确定性程度与影响性质**：

### Error

**基于当前已知事实，确定或接近确定会阻止迁移。**

即：在已知信息下，该问题会导致迁移无法完成（例如 FAT32 的目标无法容纳单个超大文件）。

### Warning

**存在真实迁移或兼容风险，但最终结果依赖复制程序、策略、环境或运行时状态。**

即：问题真实存在，但是否成为故障取决于外部因素（例如目标已存在同名对象，最终行为取决于复制程序的重名策略）。

### Info

**通常不会阻止文件内容迁移，但存在值得用户知道的行为变化、能力差异或元数据变化。**

即：内容能到达，但用户可能失去或改变了一些东西（例如某些元数据、时间戳精度、reparse point 语义）。

## 6. 成功扫描不等于复制会成功

扫描结束且未发现问题时，结论**只能**表述为：

> **"No known blocking issue was detected."**

**不能**表述为：

> ~~"The copy is guaranteed to succeed."~~

原因：CopyPreflight 只能基于它**实际观测到**的事实判断。目标能力可能是 Unknown，运行时状态（权限、锁、网络、磁盘故障）可能变化，复制程序的行为可能与本工具的假设不同。因此本工具只能报告"未发现已知阻塞问题"，不能给出任何保证。

## 7. v0.1 范围（已冻结）

v0.1 计划包含以下能力：

- 源目录 + 目标目录
- 递归源目录 inventory
- 文件数、目录数、逻辑总容量
- 目标可用空间
- FAT32 单文件大小限制
- 完整目标路径兼容性风险
- 单路径组件长度
- Windows 文件名 / 保留名称兼容性
- 已存在目标对象冲突
- file ↔ directory 类型冲突
- 无法读取的源文件
- 无法枚举的源目录
- reparse point / symlink / junction 的发现和分类
- 有选择的文件系统能力 / 元数据风险提示
- 扫描进度
- 取消扫描
- Error / Warning / Info findings
- 对每项 finding 提供**由确定规则生成**的文字解释和建议

## 8. 明确延期 / 不属于 v0.1

以下内容被明确排除在当前范围之外，**未经后续里程碑明确授权不得实现**：

- 实际复制或移动
- 自动修复
- 自动重命名
- 权限修改
- 格式化
- 文件 hash / 全内容完整性读取
- VSS / locked-file backup
- 精确模拟 Explorer / Robocopy / TeraCopy / FastCopy 行为
- 完整 ACL preservation simulation
- hard-link topology preservation
- Unicode normalization 深度兼容分析
- OneDrive / Google Drive 等云盘专项规则
- Linux / macOS 专项目标兼容模式
- CSV / JSON / HTML 报告导出
- Explorer shell extension
- plugin system

## 9. 建议的性质

对每项 finding 给出的建议是**文字建议**，依据确定规则生成。它是解释性的，不是可执行的自动操作。CopyPreflight 不会替用户做任何变更。
